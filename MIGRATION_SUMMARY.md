Hybrid processing strategy:
```typescript
const useAI = process.env.OPENROUTER_API_KEY && 
              process.env.NEXT_PUBLIC_AI_ENABLED === 'true';

if (useAI) {
  // AI-powered extraction with Minimax M2.5
  const aiResult = await extractDocumentData(textContent);
  const classification = await classifyDocument(textContent);
} else {
  // Fallback to rule-based pipeline
  const result = await runIngestionPipeline(...);
}
```

**Benefits**:
- Automatic fallback if AI unavailable
- Response includes processing method (`"ai"` or `"rule-based"`)
- No breaking changes to existing API contract

## 🔧 Required Configuration for Railway

### Step 1: Add PostgreSQL Database
In Railway dashboard:
1. Click **"New"** → **"Database"** → **"Add PostgreSQL"**
2. Link to your web service
3. `DATABASE_URL` is auto-generated

### Step 2: Set Environment Variables

| Variable | Value | Notes |
|----------|-------|-------|
| `DATABASE_URL` | *(auto)* | Generated by Railway PostgreSQL |
| `NEXTAUTH_SECRET` | `openssl rand -base64 32` | Generate locally |
| `NEXTAUTH_URL` | `https://your-app.railway.app` | From Railway |
| `OPENROUTER_API_KEY` | `sk-or-v1-...` | From OpenRouter dashboard |
| `NEXT_PUBLIC_AI_ENABLED` | `true` | Enable AI features |
| `SMTP_HOST` | `smtp.gmail.com` | Email server |
| `SMTP_PORT` | `587` | SMTP port |
| `SMTP_USER` | `your-email@domain.com` | Email username |
| `SMTP_PASS` | `********` | Email password |

### Step 3: Initialize Database Schema

**First deployment only**:
```bash
railway run npx prisma db push --schema=packages/db/prisma/schema.prisma
```

Or add to build command temporarily:
```bash
prisma generate --schema=packages/db/prisma/schema.prisma && 
npx prisma db push --schema=packages/db/prisma/schema.prisma && 
npm run build --workspace=apps/web
```

## 🆘 Troubleshooting

### "Prisma Client not found"
**Solution**: Ensure build command includes:
```bash
prisma generate --schema=packages/db/prisma/schema.prisma
```

### "OpenRouter API Error 401"
**Solution**: Verify `OPENROUTER_API_KEY` in Railway variables

### "Database connection failed"
**Solution**: Check `DATABASE_URL` format:
```
postgresql://user:pass@host:port/db?schema=public
```

### "AI features disabled"
**Solution**: Set `NEXT_PUBLIC_AI_ENABLED="true"` (string, not boolean)
